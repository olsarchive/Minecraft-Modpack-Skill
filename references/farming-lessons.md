# 农场同步与集中返修：按症状查阅

这些是特定版本中观察到的案例，不是永久禁用名单。

## 任务页崩溃：可解析不等于能渲染

车万女仆 1.5.3 / MC 1.21.1 的 entity_placeholder 图标组件 `touhou_little_maid:recipe_id` 要短值 `spawn_box`。读取器自动拼接 `touhou_little_maid:altar_recipe/`；传入 `touhou_little_maid:altar/spawn_box` 产生第二个冒号，在 FTB 绘制时崩溃。用崩溃栈定位读取器，核对当前 JAR 正常配方输出，只修组件值，保留任务/条件/奖励身份和存档进度。

**不能全局截短同名字段**：Patchouli 页面自己的 `recipe_id` 可要求完整资源 ID。对同组件做一次批量检查，覆盖任务、脚本、活动数据包与模组资源；说明是否未解码存档二进制物品。标题页和女仆工作 GUI 不能证明 FTB 特殊图标章节正常，最终抽样要包含该入口。

## 客户端与性能

- Epic Fight 21.14.1 的未绑定提示键路径曾调用 `glfwGetKey(-1)`；守卫确切未绑定分支，不改旧键位。OrderToCook 摩托车 GLFW 路径另行核实，不能把同一错误字符串全归给一款模组。
- EMF 3.3.2 / SelfExpression 2.22a 曾重复包装特定动态模型。避免重复包装不等于修复提供者全部模型重建，也不证明具体 FPS 增益。
- 任务渲染崩溃与系统内存 90% 分别记录；无同期进程内存证据不能称内存泄漏。不要盲目扩大 Java 堆或复现到整机再次卡死。
- 帧率比较固定地点、朝向、加载完成状态与画质/光影，再采样耗时。模组数、普通警告、低 GPU 占用不能单独定因；无对照不承诺提升 10 帧。

## 原生玩法与实际入口

- 女仆工作 GUI 抽样需要主人、空手、不潜行、女仆未睡觉；物品右键拦截不是永久失效。
- 强制订单命令只定位局部路径，不替代自然营业和结算。钓鱼 GUI 出现不等于奖励发放。合并成一次代表性试玩，不无限逐项重开。
- 未绑定的新功能要交付实际可搜索标签。SDM Shop 3.3.1 曾显示 `key.sdmshop.shopr` / `key.category.sdmshopr`，搜 `sdm`；Combat Roll 的“未”可表示未绑定，不是时辰或故障。
- 保留作者独立商店货币、价格和自然获取链，不自动兑换旧钱包。旧档统计可触发新成就自动补发武器，不能误称开局赠品。
- 酒庄查结构模板、处理器、机器/方块提供者；删发酵设备只剩建筑外观，不是作者酒庄玩法。自然生成还需新区域验证。
- 同时跨游戏版本和加载器（例如 26.1 Fabric / Java 25 到 1.21.1 NeoForge）不是简单桥接。先查原生发布和实际接口；公开源码不代表低成本，改版本声明不是移植。
