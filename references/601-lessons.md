# 跨版本收尾与执行效率：6.0.1 实际返修

这些是条件与机制，不是固定版本号、目录名或每批必跑的全包测试。

## 减少无效往返

- 一个已授权总任务持续推进到可交付边界。锁定来源、真实 MAIN、候选依赖图和当前台账，独立离线链成批完成；不把审计、生成候选、写入、读回拆成多轮请示。
- 保留每项的具体证据和下一步，不以 `blocked_confirmed` 重命名“未调查”。依赖扫描器未理解版本语法、Connector 名称映射或父类方法时，标为不确定；先修检查器，不能把一批误报当硬冲突。
- 比较调用的 owner/name/descriptor 及映射后继承链。曾把映射未解析的 15 个方法误称真实缺失；单纯常量池搜索无法证明可调用或缺失。
- 源码小改只在已确认 API 断点上做；优先原生构建。CobbleEMI/CobbleDex 的 SpawnBucket 删除不能只放宽依赖声明；Wild Extras 方法签名、Fabric/NeoForge Mixin 描述符也要查真实调用。
- 复用未变条件下的证据，固定最终组合后一次集中抽样。排错首因修复后只重测影响链；不要每轮全盘扫描、重新下载、复制世界或重做所有旧玩法。

## 资源包是活动依赖，不只是文件

- 读作者实际启用列表、包内资产、当前资产消费者和最终提供者。已复制≠已启用；放在 required_data 中也不能一概视为客户端材质已加载。
- 用户要求保留旧资源时，保留旧条目及相对顺序；新资源按冲突规则插入。默认保留本地修复/动画优先级，需要新包胜出时记录具体重叠路径。不要启用全部 GUI、美化、音乐来代替必要资源核对。
- 同哈希别名去重，原文件名不是版本证据。旧 JoStar 大集合 1.7 覆盖 1.8 动画曾导致实体同步解析崩溃；必要时升级活动内容，同时保留启用条目。
- Minecraft 1.21.1 客户端资源格式是 34，数据包格式是 48；兼容范围按资源侧判断。必要来源的旧格式例外只加其自身，不能修改 metadata 冒充渲染通过。
- 新资源启用后检验 affected resolver/model/poser/texture 与条件动画覆盖；磁盘和 settings 通过不能代替重新加载后的画面。原光影与反贴图错乱修复必须保留。
- 游戏退出后刷新 options 快照。只改授权列表；全部旧键位、其他选项行、原包字节和光影有效配置单独核对。MAIN 不整体接收 TEST options。

## 奖励和存档

- 发放聊天、事件日志、Inventory.add 返回成功均不是实物到账证据。创造模式满背包可能吞掉未接收栈并返回成功；奖励验收用生存模式、足够空位并查实际物品/容器。
- 原生胜利袋、按物种发币、开袋与冷却、兑换/佩戴分别记录。随机未命中不是故障；不提高概率、伪造胜利或手动给物品冒充自然掉落。
- 旧硬币迁移先全量找真实物品栈，不以已知映射表过滤扫描。用作者精确 coin_meta；无等价项不近似替换。
- 迁移当前 MAIN 的目标字段，保留数量、未知 custom_data、非目标组件和所有其他 NBT；验证非目标语义不变及二次执行零改动。绝不复制 TEST 的玩家文件/箱子/世界回退正式进度。
- 旧 species 硬币掉落与新版原生事件重复或引用退役物品时，只退役目标旧入口，保留非币奖励；自然事件仍需单独验收。

## 主包、朋友包与清理

- 用户接受抽样后按实际已通过范围交付，未测随机/外观项如实保留；不要改称全量稳定，也不要因此无限保留全部测试实例。
- 主包应用使用增量清单，退役旧活动 JAR，跳过 TEST 缓存、调试脚本、临时任务、开荒物品和个人测试进度。对应正式世界补丁按路径迁入；不要镜像整目录。
- 从已同步 MAIN 导出标准、自包含 mrpack：模组、本地小适配、任务、脚本、资源、按键和光影一起收齐；加载器精确锁定。朋友新建导入实例，不向旧 mods 上覆盖，避免注册表不一致和重复旧包。
- 排除账号/令牌、私人世界、背包/宝可梦进度、地图轨迹、客户端遭遇数据库、日志和临时探针。压缩包逐成员哈希、设置一致性和路径结构验证；朋友电脑实际启动仍独立标记。
- 清理前核对主包清单、目标实例占用与独有进度；保留必要短期回滚与简明证据。启动器用支持的删除/移除入口，不手改数据库；支持入口不可用时清理其余已核对文件并说明阻塞，不伪造登记已清。
- 删除只用解析后的精确绝对目标，在同一 shell 内完成，拒绝联接/符号链接越界。报实际释放字节，不把磁盘空间说成运行内存。
